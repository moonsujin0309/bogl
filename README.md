# 보글 · BOGL°

유튜브에서 발견한 요리를 저장하고, **영상·재료·챕터를 함께 보며 따라 만드는** 요리 도구.

2026-09-09부터 영상 레시피 보기가 중심입니다. 요리 계획과 장보기 계산도 이어서 사용할 수 있습니다.

화면은 오프화이트·먹색·버밀리언 색상과 크고 작은 음식 사진으로 구성합니다. 모바일에서 메뉴가 먼저 보이도록 제목을 줄였습니다. PC의 요리 찾기는 제목과 메뉴가 좌우로, 모바일에서는 위아래로 이어집니다. 로컬 파일에서는 모바일 폭으로 미리 보고 오른쪽 아래 버튼으로 PC 화면과 비교할 수 있습니다.

## 하는 일

- **요리 찾기**: 김치찌개·알리오 올리오 파스타 등 메뉴 키워드 6개를 먼저 보여줍니다. 골고루·한식·양식·일식·중식 분류를 고르면 메뉴가 바뀌고 선택을 이 기기에 기억합니다. 메뉴를 누르면 해당 요리의 YouTube 검색을 엽니다. 직접 요리·재료 이름을 입력할 수도 있습니다. 간단한 조리·적은 재료·자세한 설명, 식사 종류 취향은 검색어에 반영합니다. 일반 영상과 쇼츠 모두 지원하며 영상 종류는 YouTube 검색 필터에서 고릅니다.
- **첫 화면**: 처음에는 요리 찾기, 저장한 영상이 있으면 내 영상부터 엽니다. 기본 레시피는 찾기 화면 아래, 요리 계획은 보관함 아래에서 사용할 수 있습니다.
- **내 영상**: 영상이나 재생목록 링크로 저장하고 이름·채널·재료로 검색합니다. 재료 입력 없이도 먼저 저장할 수 있습니다.
- **요리 화면**: 영상은 재료·챕터 탭을 바꾸어도 유지됩니다. 재료 체크, 인분 환산, 챕터 이동, 10초 되감기, 타이머를 사용할 수 있습니다.
- **이어서 만들기**: 마지막 요리의 영상 위치·재료 체크·인분·단계를 이 기기에 저장합니다. 요리를 완료하면 이어 보기에서 빠집니다.
- **설명란 정리**: 유튜브 설명란의 재료와 타임스탬프를 파싱합니다. 설명란에 없다면 직접 입력하며, 없는 레시피를 만들어내지 않습니다.
- **장볼 것**: 재료 미입력 영상은 합산에서 빠졌다는 안내를 표시합니다.

## 요리 계획

단위는 **폴더** 하나입니다. 폴더가 갖는 것은 이름 · 담은 요리 · 며칠에 걸쳐 먹나, 셋뿐이에요.

- **며칠 = 5** → 요일 배치. 상하기 쉬운 재료를 먼저 쓰고, 국물 요리가 연달아 오지 않게 하고, 장보기를 최소 횟수로 나눕니다. 오늘 손질할 때 내일 것도 같이 하라는 밑작업도 붙어요.
- **며칠 = 1** → 시간 배치. 전날 · 당일 아침 · 먹기 직전으로 나눕니다. 집들이가 여기예요.

요리를 담는 길은 셋입니다 — 한식 공공데이터 74개 목록에서 고르기 · 유튜브 영상 링크로 · 유튜브 재생목록 통째로(재생목록이 곧 폴더).

장볼 것은 마트 매대 기준(정육·계란 / 수산·건해산 / 채소·두부 …)으로 묶이고, 먹을 사람 수를 바꾸면 수량이 다시 계산됩니다. 수량은 항상 올림이에요 — 3.4개를 사러 갈 수는 없으니까요.

## 구조

```
catalog.txt   `모든 요리` 목록 (한 줄에 하나)
build.py      API 호출 → 재료 정규화 → data.json → index.html
plan.js       배치 · 매대 분류 · 재료 합산 · 유튜브 설명란 파싱 (브라우저에서 돈다)
test_plan.js  node test_plan.js — 계산 검사
test_bogl.cjs 브라우저 회귀 검사 (개발용 Playwright + Edge)
app.html      앱 템플릿 (__DATA__ · __PLAN__ · __YTKEY__ 를 build.py가 채운다)
index.html    배포 대상 (생성물)
data.json     카탈로그 + 사진 출처 (생성물)
img/          요리 사진 (생성물)
```

**서버도, 빌드 도구도, 의존성도 없습니다.** 런타임에 부르는 외부 API는 유튜브 하나뿐이고, 그것도 키가 없으면 직접 입력으로 대신합니다.
`index.html`은 생성물이니 직접 고치지 말고 `app.html`·`plan.js`·`build.py`를 고친 뒤 다시 빌드하세요.

## 다시 빌드하기

```bash
timeout 30 node test_plan.js        # 계산 검사
timeout 60 python build.py          # 캐시 재사용
timeout 120 python build.py --fresh # API에서 다시 받기
timeout 100 node test_bogl.cjs      # Playwright를 NODE_PATH로 제공. 임시 서버·브라우저는 종료 시 정리
```

인증키는 환경변수로 넣습니다. `DATA_GO_KR_KEY`는 [농림축산식품 공공데이터 포털](https://data.mafra.go.kr)에서 발급하며, **이 API는 키를 URL 경로에 넣기 때문에** data.go.kr 방식 키는 쓸 수 없습니다. `YOUTUBE_KEY`는 선택이고, 넣을 때는 반드시 HTTP referrer 제한을 걸어 두세요 — 브라우저에 노출되는 키입니다.

## 데이터 출처

레시피 74개는 **농림수산식품교육문화정보원** 공공데이터(레시피 기본정보 · 재료정보 · 조리과정)입니다.
출처는 화면에서 **레시피마다** 표시됩니다. 유튜브로 담은 요리는 그 영상이 출처예요 — 재료와 조리법은 항상 같은 데서 옵니다.

요리 사진은 **위키미디어 공용**에서 받았고 대부분 CC BY / CC BY-SA라 **표기가 라이선스 조건**입니다. 사진마다 원본·저작자·라이선스가 `data.json`에 실려 레시피 화면에 표시됩니다.
