# 보글 · BOGL°

한식 데이터로 **재료가 가장 많이 겹치는 조합**을 찾아, 장볼 것을 한 장으로 줄여주는 집밥 도구.

아무렇게나 다섯 끼를 고르면 재료를 26.8가지 사야 합니다. 겹침을 계산해서 고르면 **13가지면 됩니다.**

## 하는 일

레시피 300개에서 5개를 뽑는 조합은 수십억 개입니다. 사람이 손으로 못 하는 계산이에요. 그걸 빌드 타임에 끝내두고, 화면은 결과만 보여줍니다.

- **이번 주** — 초보환영 · 30분 이하 레시피 중 겹침이 가장 큰 다섯 끼
- **집들이** — 손님 상차림 여덟 가지

먹을 사람 수를 바꾸면 수량이 다시 계산됩니다. 장볼 것은 마트 매대 기준(정육·계란 / 수산·건해산 / 채소·두부 …)으로 묶여요.

## 구조

```
build.py     API 호출 → 재료명·수량 정규화 → 겹침 계산 → data.json → index.html
app.html     앱 템플릿 (__DATA__ · __HERO__ 를 build.py가 채운다)
index.html   배포 대상. 데이터와 사진까지 인라인된 단일 파일 (생성물)
data.json    계산 결과 (생성물)
```

**서버도, 빌드 도구도, 의존성도 없습니다.** `index.html` 하나로 열립니다.
`index.html`은 생성물이니 직접 고치지 말고 `app.html`이나 `build.py`를 고친 뒤 다시 빌드하세요.

## 다시 빌드하기

```bash
python build.py          # 캐시 재사용
python build.py --fresh  # API에서 다시 받기
```

인증키는 환경변수 `DATA_GO_KR_KEY`로 넣습니다. [농림축산식품 공공데이터 포털](https://data.mafra.go.kr)에서 발급하며, **이 API는 키를 URL 경로에 넣기 때문에** data.go.kr 방식 키는 쓸 수 없습니다.

## 데이터 출처

레시피는 **농림수산식품교육문화정보원** 공공데이터(레시피 기본정보 · 레시피 재료정보)입니다.
출처는 화면에서 **레시피마다** 표시됩니다 — 다른 곳 레시피를 더해도 그대로 드러나도록 만들었습니다.

대표 사진은 위키미디어 공용에서 받은 임시 자산이며, 배포 전에 교체 대상입니다.
